           ENSIKLOPEDIA FLAGS • ARTI TANDA - DAN --
        

        

          Kupas Tuntas Tanda - dan -- di Git
        

        

          Dalam perintah terminal git [perintah] [flag/opsi] [argumen], tanda strip berfungsi seperti sakelar pengubah perilaku perintah Git. Pahami 3 jenisnya agar tidak pernah salah pencet flag berbahaya!
        

      


      
      

        

          

            - (Short Flag)
            Singkatan 1 Huruf
          

          
Satu Strip = Singkatan Cepat

          

            Dipakai untuk opsi harian agar mengetiknya super cepat. Contoh: -m (pesan), -u (upstream), -b (branch), -f (force).
          

        


        

          

            -- (Long Flag)
            Kata Penuh
          

          
Dua Strip = Nama Opsi Lengkap

          

            Opsi spesifik yang lebih jelas dibaca manusia. Contoh: --force, --force-with-lease, --amend, --hard, --oneline.
          

        


        

          

            -- (Path Separator)
            Berdiri Sendiri
          

          
Pemisah Branch & File

          

            Memisahkan nama branch di kiri dengan nama file di kanan. Contoh: git checkout -- index.html agar Git tidak bingung jika ada branch & file bernama sama.

           SANDBOX POHON BRANCH
        

        

          Perbandingan Visual: Git Merge (--no-ff) vs Git Rebase
        

        

          Klik tombol aksi di bawah untuk membangun pohon commit-mu sendiri! Perhatikan bagaimana Git Merge (--no-ff) menciptakan bentuk berlian (diamond commit) dengan 2 induk, sedangkan Git Rebase meluruskan sejarah menjadi satu garis rapi.
        

      


      

        

          

            Branch Aktif (HEAD):
            main
          

          

             main
             feature
             HEAD
          

        


        
        

          
        


        
        

          
          
          
          
          
          
          
        


        
        

          

            
Narasi Graf Saat Ini:

            

              Graf dimulai dengan 2 commit di main dan 1 commit cabang di feature. Klik 🔗 Git Merge (--no-ff) atau ⚡ Git Rebase untuk membandingkan hasilnya!
            

          

          

            
🔗 Git Merge (--no-ff): Membentuk diamond commit baru; sejarah cabang apa adanya tetap terlihat.

            
⚡ Git Rebase: Memindahkan pangkal commit ke ujung terbaru; riwayat jadi 1 garis lurus bersih.
